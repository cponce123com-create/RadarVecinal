Quiero que diseñes y construyas un MVP funcional y visualmente premium de una plataforma web PWA llamada “Radar Vecinal”.

OBJETIVO DEL PRODUCTO
Radar Vecinal es una plataforma de reportes ciudadanos, alertas urgentes, mapa de incidencias y memoria distrital. No debe verse como una app genérica de dashboard. Debe sentirse como una mezcla entre seguridad comunitaria, mapa interactivo, red vecinal y sistema de inteligencia territorial.

STACK OBLIGATORIO
- Next.js con App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- Prisma ORM
- PostgreSQL preparado para Neon
- Auth.js / NextAuth para autenticación
- Mapbox para el mapa
- Cloudinary para imágenes
- Firebase Cloud Messaging preparado para notificaciones push
- Resend preparado para correos
- Arquitectura lista para desplegar en Render

REQUISITOS GENERALES
- Diseño mobile-first pero que se vea excelente en desktop
- Debe funcionar como PWA
- UI moderna, elegante, oscura y tecnológica
- Nada de apariencia infantil o de plantilla genérica
- Debe tener componentes reutilizables
- Código limpio, estructurado y escalable
- Crear datos mock iniciales para demostrar funcionamiento
- Usar buenas prácticas de estructura de carpetas
- Preparar variables de entorno en .env.example
- Preparar README con pasos de instalación y despliegue

IDENTIDAD VISUAL
Quiero un estilo premium y tecnológico:
- Fondo negro carbón / azul muy oscuro
- Detalles azul eléctrico y gris grafito
- Rojo intenso para alertas críticas
- Verde controlado para estados resueltos
- Tipografía moderna tipo Inter / Geist / Satoshi
- Bordes redondeados modernos
- Sombras suaves y profundidad elegante
- Microinteracciones discretas
- Sensación de producto tipo startup seria, no app municipal antigua

2. HOME PRINCIPAL
El home debe ser la pantalla más importante. Debe ser altamente intuitivo, visual e interactivo.

Estructura exacta del home:
- Header sticky con logo Radar Vecinal, ubicación actual, notificaciones y perfil
- Tarjeta superior con resumen:
  - alertas activas
  - incidentes de hoy
  - zona más crítica
  - botón ver todo
- Mapa principal interactivo grande en el centro
- Botón de pánico flotante fijo y muy visible
- Bloque de acciones rápidas:
  - Reportar incidente
  - Ver alertas activas
  - Menor perdido
  - Historial
- Feed de actividad reciente
- Resumen estadístico de hoy en tu zona
- Un espacio sutil para publicidad local no invasiva
